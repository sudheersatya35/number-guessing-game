
# Number Guessing Game

## About
A simple beginner Python project in which the
computer chooses a random number between 1 and 100.

## Features
- Random number generation
- User input
- Higher and lower hints
- Attempt counter
- Invalid input handling

## Requirements
- Python 3

## How to Run
Run the following command in your terminal:

python guessing_game.py

## Concepts Used
- Variables
- Loops
- If-else statements
- Random module
- Exception handling
